A Python-based command-line tool designed for Judo athletes to log their match history, calculate win rates, and analyze their most effective techniques. 
Judo_test.py file is the first program prototype.
Judo_Tracker_V2.py is a way better version of the prototype, with the data saving feature.
Judo_Tracker_V2.1.py is the most recent, complete for now, program with a new DELETE feature.
